# poc-log

`docs/poc-findings.md` は PoC コード破棄後に唯一残る成果物。判定の出た実験だけを対象にする。

## 記録基準

書く: 採否を動かした観測 / 想定とのズレ / 行き止まりと理由 / 制約・限界値 / 設計を左右する選択と理由

書かない: 検証項目に紐づかないもの / 公式ドキュメントで足りるもの（参照 URL 1 行に置換）/ 自分のミス由来の一時トラブル / 作業ログ・次の予定 / PoC コードの実装詳細 / 「動いた」だけのもの

迷ったら書かない側に倒す。判定は「コードを全部消した 3 ヶ月後、この行で本実装の判断が変わるか」。

## 形式

「検証項目と結果」に追記。項目が無ければ先に足す。1 エントリ 6 行以内。超えるなら論点が混ざっているので分ける。

```
### <検証項目> — YYYY-MM-DD

- 試したこと: 1 行
- 事実: 観測したものだけ（実行結果・数値・エラー）
- 解釈: そこから言えること
- 判定: 採用 / 不採用 / 判定不能
- 再現: コマンド + バージョン（後で追検証しうる場合のみ）
```

## ルール

- 「採用」は「本実装に持ち込むもの」へ、後に響く「不採用」「判定不能」は「残課題」へ 1 行追加
- 重複は追記せず既存行を差し替える
- 書き込み前に内容を提示して承認を得る
