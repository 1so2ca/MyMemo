# share-session

## 用途

- 現在または指定セッションの会話を「読み物」として共有可能な形に変換する
- 個人情報・パス・認証情報をマスクし、長い応答を圧縮する

## 入力

- 引数: `[input.jsonl] [topic]`
  - `input.jsonl`: セッションの jsonl。省略時は最新セッション
  - `topic`: 出力ファイル名に使う短いトピック（例: `arch-discussion`）。省略時はユーザに尋ねる

## 手順

1. `/extract-md` を呼んで生 md を一時生成（出力パスを保持）
2. 生 md にマスキングを適用
3. マスク後の内容に圧縮を適用
4. `docs/sessions/YYYY-MM-DD-<topic>.md` に保存
5. 一時ファイルを削除
6. 保存先パスをユーザに表示

## マスキングルール

正規表現で以下を置換:

- 絶対パス: `[A-Z]:\\\\[^\\s"'<>|]+` および `/(?:Users|home)/[^\\s"'<>|]+` → `<PATH>`
- メールアドレス: `[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}` → `<EMAIL>`
- API キー / トークン候補:
  - `sk-[A-Za-z0-9_-]{20,}` / `xoxb-[A-Za-z0-9-]+` / `ghp_[A-Za-z0-9]{20,}` / `Bearer\\s+[A-Za-z0-9._-]+` → `<TOKEN>`
- ユーザ名 `lic` / マシン名 → `<USER>` / `<HOST>`（環境変数の `$env:USERNAME` / `$env:COMPUTERNAME` を参照）
- IP アドレス（プライベート帯）: `192\\.168\\.\\d+\\.\\d+` / `10\\.\\d+\\.\\d+\\.\\d+` → `<IP>`

マスク漏れが疑わしい箇所は `<REDACTED>` で目視置換し、ユーザに最終確認を求める。

## 圧縮ルール

- 各ターンを次の構造に再構成:
  - **User**: 原文をそのまま保持（短いことが多い）
  - **Assistant**: 「要旨 3 行」 + 「キー判断・採用案・最終構成のみ抜粋」
- ツール呼び出しの羅列は「コード探索」「Web 検索」「ファイル作成」などの一語要約に置換
- AskUserQuestion の選択肢と回答は full で残す（議論の分岐が後で読めるため）
- 最終的な決定・合意事項は full で残す
- コードブロックは「変更箇所が論点」の場合のみ残し、それ以外は要約

## 出力フォーマット

```
# <topic>

- 日付: YYYY-MM-DD
- 主題: 一行サマリ

---

## ターン N

**User**: ...

**Assistant 要旨**:
- ...
- ...
- ...

**抜粋**:
> （必要な部分のみ）

---
```

## 注意

- マスク後の md は必ずユーザに表示してから保存・共有に進む
- 個人情報の検出に自信がない箇所はマスクを優先する（過剰マスクは許容、漏れは許容しない）
